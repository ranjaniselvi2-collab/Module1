1. ### Conditional Statements in Python: Even or Odd Checker

 ### Aim:
3. To write a Python program to check whether a given number is Even or Odd using conditional statements.

 ### Algorithm:
1. Start the program.

2.Read a number from the user.

3.Check whether the number is divisible by 2 using the modulus operator %.

4.If the remainder is 0, print "Even Number".

5.Otherwise, print "Odd Number".

6.Stop the program.

### Code:
```
num = int(input("Enter a number: "))

if num % 2 == 0:
    print("Even Number")
else:
    print("Odd Number")
```
### Output:
```
Enter a number: 8
Even Number
```
### Result:
Thus, the Python program to check whether a number is Even or Odd using conditional statements was executed successfully.
